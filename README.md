# Netflix EDA Project 🎬

## Overview

This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

The main goal of this project is to analyze Netflix content trends, clean the dataset, visualize important patterns, and derive meaningful insights from the data.

---

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

---

## Dataset

The dataset contains information about Netflix Movies and TV Shows such as:

* Title
* Director
* Cast
* Country
* Release Year
* Rating
* Duration
* Genre

---

## Project Workflow

### 1. Data Loading

Loaded the Netflix dataset using Pandas.

### 2. Data Understanding

Analyzed:

* Dataset shape
* Column names
* Data types
* Missing values

### 3. Data Cleaning

Handled missing/null values using Pandas.

### 4. Exploratory Data Analysis

Performed analysis on:

* Movies vs TV Shows
* Top countries producing Netflix content
* Ratings distribution
* Release year trends
* Content addition trends

### 5. Data Visualization

Created charts using Matplotlib for better understanding of patterns and trends.

---

## Key Insights

* Netflix contains more Movies than TV Shows.
* USA and India contribute a significant amount of content.
* Content additions increased rapidly after 2015.
* TV-MA is one of the most common content ratings.
